# Coze / Dify 笔记——把 19 课学的翻译成平台积木

> 这篇不是新课，是你前面 19 课（手写 agent）的**翻译表**。
> 目标：JD 里"会用扣子/Dify"你会了，同时你能说清楚每块积木底下是什么原理。
> 配套动手任务在文末，10 分钟。

## 一、Coze 和 Dify 是什么

| | Coze（扣子） | Dify |
|---|---|---|
| 谁家的 | 字节跳动 | 开源社区项目 |
| 怎么用 | 网页拖拽，coze.cn 国内版，手机号登录**免费不用绑卡** | 可自己部署到公司服务器 |
| 特点 | 发布渠道多（抖音/公众号/飞书…），JD 常提"会用扣子" | 私有可控，技术岗常提 |
| 本质 | 把你手写 agent 的底层封装成**拖拽积木** | 同左 |

一句话：**前 19 课你手写的东西，它们把它做成了积木。** 你不是在学新东西，是在翻译。

## 二、映射表：你写的每一课 → 平台里的积木

| 你手写的（课） | 扣子/Dify 里的积木 |
|---|---|
| 对话历史 messages 循环（1-2 课） | 默认就有，不用管 |
| 工具循环 stop_reason（2 课） | **插件**：自带几十个 + 可自定义 |
| MAX_ITERS 兜底（3 课） | 平台后端兜底 + 工作流里加"条件判断"节点 |
| 打转检测（4 课） | 工作流里加防重逻辑 |
| RAG 切块→检索→拼接（16 课） | **知识库**：上传文件 → 勾选启用，自动切块+向量化+检索 |
| 向量嵌入 embedding（17-18 课） | 知识库内置向量模型，不用自己下载 bge |
| 上下文管理 / 摘要（10-11 课） | 平台默认做，可设置 |
| 流式打字机（14 课） | 默认就是流式 |
| MCP 外部工具（15 课） | 插件市场 + 自定义 MCP（JSON-RPC 协议照样用） |
| 多 Agent 双脑（19 课） | **多 Agent 工作流**：多个节点，各配各的 prompt，节点间传消息 |
| 裁判打分 LLM-as-judge（9 课） | 工作流加"LLM 节点"当评审 → 条件分支：通过交付 / 需改回写手 |
| 优雅降级不崩（贯穿） | 工作流节点的失败处理：出错走错误分支，不让整个流死掉 |

> 💡 记住这张表，面试时你就是"既会拖积木、又懂积木底下"的人。

## 三、为什么不白学（面试官没写出来、但最想要的）

### ① 面试追问原理，拖积木的人答不出
例：面试官问"知识库为什么有的内容搜不到？"
- 拖积木的人：卡住。
- 你：关键词打分只认字面（番茄搜不到西红柿）；向量检索靠余弦相似度，但真模型没有"正好 0"，阈值要按语料调（`REAL_MIN_SIM=0.45`）……（16-18 课的主场）

### ② 平台出 bug，拖积木的人只能干瞪眼
知识库捞错内容 → 查切块/阈值；工作流卡死 → 查是不是节点循环；插件调用失败 → 查 JSON-RPC 通信。**每一层你都亲手拆过**，你看到的是你写过的那几行代码。

### ③ 平台做不到的，你能用代码补
积木覆盖 90% 场景，剩下 10%（特殊工具、接公司内部系统、自定义检索）平台没有。拖积木的人说"做不了"；你打开 `agent-claude.py` 改两行补上。**"会拖"是上限，"会写"没有上限。**

### ④ 工具会换，原理不会
扣子明天可能被替代，但工具循环、护栏、RAG、向量检索、多 Agent 协作这些**原理十年不过时**。你学的不是"怎么操作扣子"，是这些平台的**公共地基**。

### 类比：开车 vs 修车
> 只会用平台 = 会开自动挡；手写 agent = 会手动挡 + 懂发动机原理。
> 公司要"又会开、又懂车"的——路上必然抛锚，只有懂车的人能修。

## 四、面试答法（背这句）

> "我手写过完整的 agent（工具循环、护栏、上下文管理、RAG 向量检索、多 Agent 协作），也用过扣子/Dify 这类平台。**平台就是把底层封装成拖拽积木**：知识库对应 RAG 管线，插件对应工具循环，工作流节点对应多 Agent 协作。所以我用平台能知道每块积木背后是什么、出了问题在哪一层。平时也用它快速搭原型验证想法。"

关键：**既说平台（JD 要求）又说原理（你没有的别人也没有）。**

## 五、动手任务（10 分钟）

1. 打开 coze.cn，手机号登录（免费，不用绑卡）。
2. 创建智能体"杭州旅游助手"。
3. 左侧菜单 **知识库** → 上传 `learn-agent/knowledge.md`（杭州攻略）→ 开启检索增强。
4. 问它"龙井茶怎么泡"——看它能不能答（这就是 RAG，扣子自动切块+向量化+检索，16-18 课学的）。
5. 再玩 **工作流**：把"写手"节点和"评审"节点串起来（第 19 课双脑的积木版）。

做完你会发现：**每一块积木，你都认得它的底下。**
