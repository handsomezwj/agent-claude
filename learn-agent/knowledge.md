# 杭州攻略

杭州是浙江省的省会，位于钱塘江畔，以西湖闻名，是一座有着两千多年历史的城市。这座城市既有深厚的历史文化，也有繁荣的现代商业，是长三角地区的中心城市之一。

西湖是杭州最出名的景点，环湖一周约十五公里。西湖十景包括断桥残雪、苏堤春晓、三潭印月、雷峰夕照等。春天桃花盛开，夏天荷花满湖，秋天桂花飘香，冬天可以看断桥残雪，四季都有不同的风景。

龙井茶是杭州最著名的特产，产自西湖边的龙井村。茶叶分明前、雨前等档次，明前龙井（清明前采摘）最为珍贵。冲泡龙井茶用八十度左右的泉水最佳，第一泡的香气最浓。

杭州的美食很有特色。西湖醋鱼是杭帮菜的招牌，东坡肉肥而不腻，片儿川面汤鲜味美，葱包桧儿是街头小吃。觅食推荐去河坊街、中山南路一带，老字号扎堆，价格也公道。

杭州的交通很方便。地铁目前有十二条线路在运行，可以直达西湖、高铁站和机场。市内共享单车非常普及，很多人选择骑自行车环游西湖，既省钱又惬意。

杭州也是互联网之都，阿里巴巴、网易等大公司都在这里设有总部或重要分部，直播电商、跨境电商的产业非常发达。来杭州工作、创业的人越来越多。
