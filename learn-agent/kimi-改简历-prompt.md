# 改简历话术（喂给 Kimi / 任何 AI 聊天工具）

> 用法：复制话术 A 或 B 整段，按【】提示替换内容，发给 AI。
> 结构对应第 20 课提示词工程：角色（三要素）+ 规则 + 输出格式。

---

## 话术 A：通用版（有目标 JD 时用）

```
你是一位资深技术面试官 + 简历顾问。我找大模型应用 / Agent 开发的岗位，帮我改简历。

【我的简历】
（粘贴你的简历原文）

【目标岗位 JD】
（粘贴招聘 JD 原文）

按 4 步来：
1. 诊断：找 3~5 条"简历和 JD 不匹配"的硬伤（比如 JD 要求的技术你没写、亮点没用业务话术、被无关内容稀释）。
2. 改写：逐条改成贴合这个 JD 的版本——亮点前置、量化结果（用了什么技术 → 解决什么问题 → 带来什么结果）、删无关废话。
3. 对照表：给"改前 vs 改后"对照表，说明每处为什么改。
4. 给 3 个反问：面试官最可能盯哪几处深挖，我怎么准备。

要求：只基于我给的简历改写，不许编造经历；务实不浮夸；用中文。
```

---

## 话术 B：项目描述版（简历落后于实际进度时用）

> 什么时候用这个：你简历里写的能力比你实际会的老了半截（漏了流式/MCP/长记忆/向量检索），
> 或者数字低估（比如写"5 个测试剧本"但实际 176 个）。这版把**真实素材**喂进去，让 AI 以事实为准改。

```
帮我把简历改一版。下面是【现状简历】和【正确素材】，要求：
1. 以【正确素材】为准，改掉我简历里过时、低估的内容（尤其测试数字、漏掉的新能力）；
2. 合并重复项（我简历里"多模型适配/RAG/Guardrail"各出现了两次，合并成一条）；
3. 加强量化：能用数字就用数字，但不许编造；
4. 删掉跟项目无关的凑数条目（比如"前端与可视化"出现在命令行 Agent 项目里就不合适）；
5. 措辞贴合"AI 应用开发 / Agent 开发工程师"岗位。

【现状简历】
（贴你现在的简历全文）

【正确素材】
项目一 · 手写 AI Agent（agent-claude.py，独立项目，2025.10—2026.08）
从零手写交互式 Agent，不依赖 LangChain 等框架。核心能力：
- 工具调用循环：stop_reason == "tool_use" 多轮编排，自定义 Shell/网页抓取/技能加载工具
- 四层生产护栏：最大轮数兜底、原地打转检测、40k Token 上下文超窗自动裁剪+摘要压缩、LLM 裁判打分
- 流式输出（打字机）；MCP 标准协议接入外部工具；RAG 检索增强（词袋向量 + bge 中文向量模型语义检索，同义词召回，余弦 0.75）；JSON 长记忆持久化（重启不忘）
- 多模型统一适配：环境变量切换 Anthropic 官方 / DeepSeek / 第三方兼容端点
- 自研 FakeModel 假模型替身，176 个 unittest 全绿，零成本验证护栏

项目二 · AI 简历助手（resume-advisor，Flask Web 应用，2026.08）
- 贴简历+JD → AI 诊断差距 / 按 JD 改写 / 8 轮多轮模拟面试（InterviewStore 内存会话，会话隔离）
- 分层架构（路由薄壳 / 业务逻辑 / 提示词 / 解析四层分离，逻辑可独立测试）
- 自制 CSRF、Jinja2 自动转义防 XSS、API 密钥仅后端 .env（公开仓库零密钥）
- 优雅降级：模型异常给用户友好提示，真实原因进日志
- 排查修复真实 Bug：DeepSeek 思考消耗 max_tokens 导致空响应，预算 2000→8000 根治
```

## 话术 C：简历里漏掉的能力 → 现成 bullet（面试官视角，可直接抄）

> 你简历最该补的是这几条——都是面试官找的关键词。按"用了什么 → 解决什么 → 结果"的句式写好了，
> 挑需要的放进 Agent 项目经历里（每条 1 行，别堆太多）。

- **流式输出**：SSE 打字机实时流式回复，老循环一行不改接入（`client.messages.stream()`）
- **MCP 标准协议**：以标准协议接入外部工具，避免为每个工具手写胶水代码，降低接入成本
- **RAG 向量检索**：词袋向量 + bge 中文向量模型双层检索，语义召回（"番茄"能搜到"西红柿"，余弦相似度 0.75），有效抑制模型幻觉
- **长记忆**：JSON 记事本持久化用户记忆，重启不忘；关键事实自动提取并注入 system prompt
- **测试体系**：自研 FakeModel 假模型替身，176 个 unittest 全绿，零成本回归验证全部护栏

---

## 为什么这么写（第 20 课温习）

- **角色**：话术开头定"资深面试官 + 简历顾问"——system prompt 三要素里的角色
- **规则**："不许编造 + 务实 + 中文"——三要素里的规则
- **输出格式**："4 步 + 对照表"——三要素里的格式，好解析、不跑偏
- **话术 B 的关键**：给 AI 提供**正确素材**当"事实锚点"——让 AI 改你的过时内容而不是自己编。这是喂数据而不是只下指令
- **话术 C**：补的是面试官搜索关键词（流式/MCP/RAG/长记忆/测试）——简历的"关键词密度"决定第一轮筛人过不过
- 改简历是"写作类"任务，温度速查表里对应 0.7（界面调不了温度，靠话术约束）

## 进阶玩法

- 改完让它"再毒舌一点，当最挑剔的面试官"——多轮迭代（第 13/19 课的评审模式，人肉版）
- 换个目标 JD 再发一遍，看同一份简历怎么"适配"不同岗位
- 把诊断结果丢回给你的 resume-advisor 里当参考，两头用
